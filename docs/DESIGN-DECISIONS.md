## 1. Fit（这东西要证明什么）

- **谁用**：任何需要替一群人处理信息的人（班委、社团/实验室负责人、课程代表等），每天开一次看有没有新通知、有没有文件要登记。
- **必须相信**：信息是新的、准的；找东西不用翻三屏；这是个能长期干活的地方，不是展示页面。
- **靠什么证明**：数字有出处、表格能扫读、状态一眼可辨、操作路径短。
- **因此风格**：克制的工具界面，而不是「有气质」的展示页。

## 2. 三个感觉词

**精确（precise）· 安静（quiet）· 有秩序（ordered）**

## 3. 八个设定

### Layout（版式）
- 侧栏 236px 固定，主区 `max-width:1120px`，内容从左边距起排。
- 侧栏三段：品牌 → 主导航 → 工作列表（AI 对话在上、群列表在下）；导航固定，列表各自滚动。
- 页面标题在内容区顶部，右侧留动作位；卡片与表格同宽。

### Spacing（间距）
- 4px 网格：4 / 8 / 12 / 16 / 24 / 32。
- 卡内 20–24，卡间 16，区块间 24–32；表格行高 40–44。

### Typography（字体）
- 界面：Inter（Windows 回退 Segoe UI / 微软雅黑），不做标题衬线。
- 数据：JetBrains Mono / Consolas，**只用于数字、时间、编号、代码**，并开 `tabular-nums`。
- 字号刻度：11 / 12 / 13 / 14 / 15 / 17 / 20 / 22 / 26 / 30。
- 大数字 30px / 600 / `-0.02em`；表格与正文 13–14px。

### Motion（动效）
- 只动颜色与背景：150ms ease-out；不做入场、不做位移。

### Color（颜色角色）
| 角色 | 值 | 用途 |
|---|---|---|
| background | `#F3F5F2` | 页面底 |
| card | `#FFFFFF` | 卡片、表格容器 |
| text | `#171A18` | 正文 |
| muted | `#5B635E` | 辅助、表头、时间 |
| primary | `#17352B` | 主按钮、选中态、头像 |
| accent | `#B23A2C` | 链接、强调、危险数字 |
| border | `#D7DBD5` | 细线、输入框 |
| sidebar | `#141815` | 侧栏 |

- 绿/琥珀/红只表状态，永远带文字（已入库 / 未下载 / 重复）。
- 不用渐变、不用彩色卡片底；状态徽章描边、不铺底。

### Surfaces（表面）
- 圆角统一 4px；按钮/输入框 4px；徽章 3px。
- 无阴影；层次靠 1px 细线 + 白底与灰底的对比。
- 控件一条高度梯：24 / 32 / 36；同排控件同高。

### Imagery（图像）
- 聊天图片一律 96px 缩略（`object-fit:cover`），点开看大图。
- 文档图片进 104px 缩略网格，24 个一页。
- 不给图片配装饰性背景或渐变。

### Copy（文案）
- 说清楚「是什么、从哪来、点了会发生什么」；不用感叹号、不做营销句式。
- 空状态区分「还没数据」与「筛掉了」。

## 4. 刻意保留 / 刻意不做

- **Inter 作为界面字**：工具页的默认选择，不是套路；有中文回退与等宽数字配合。
- **等宽字体只给数据**：审计会把「非代码文本用等宽」记为 AI tell；这里数字与日期确实是数据，保留。
- **不做暗色模式**：当前使用场景是白天办公，先把亮色做对。
- **不做侧栏收起**：只有 8 个导航项，保持常显更省一次点击。
